# IoT Devices

Android-додаток для керування розумними розетками Tuya / Smart Life з вимірюванням енергії
(напр. «20A Smart Socket EU, Power Monitor»).

## Можливості

- Вмикання/вимикання, живі дані: потужність (Вт), напруга (В), струм (А)
- **Локально по Wi-Fi** (протоколи 3.3 / 3.4 / 3.5) — швидко і без інтернету
- **Через хмару Tuya** — коли ти не вдома; режим «Авто» перемикається сам
- Графік споживання (1 год / 6 год / 24 год / 7 днів), кВт·год за сьогодні і вартість за тарифом
- Таймер (працює в самій розетці) і розклад за днями тижня
- Поведінка після відновлення світла (вимкнено / увімкнено / як було)
- Віджет на головний екран з кнопкою і потужністю
- Фоновий моніторинг з потужністю в сповіщенні
- Кілька пристроїв, автоматичний пошук IP у мережі, імпорт ключів з хмари

## Встановлення

1. Відкрий на телефоні **Releases → latest** у цьому репозиторії.
2. Завантаж `iot-devices.apk` і встанови (дозволь встановлення з цього джерела).

Кожен пуш у `main` збирає новий APK через GitHub Actions; оновлення ставиться поверх старої версії.

## Перший запуск

1. На [iot.tuya.com](https://iot.tuya.com) створи Cloud Project (Smart Home, Central Europe).
2. Скопіюй **Access ID** та **Access Secret** з Overview.
3. Devices → Link App Account → відскануй QR у Smart Life (Я → сканер).
4. У додатку: Налаштування → встав ключі → **Імпорт**.
5. Відкрий розетку → ✏️ → **В мережі**, щоб знайти IP і версію протоколу.

Ключі зберігаються лише на телефоні і не потрапляють у репозиторій.

## Будова

| Шлях | Що там |
|---|---|
| `tuya/TuyaProtocol.kt` | кадри 55AA / 6699, AES-ECB/GCM, HMAC, узгодження сесійного ключа |
| `tuya/TuyaLocalClient.kt` | постійне TCP-з'єднання 6668 з пристроєм |
| `tuya/TuyaDiscovery.kt` | UDP-пошук пристроїв (6666 / 6667 / 7000) |
| `tuya/TuyaCloud.kt` | Tuya OpenAPI з підписом HMAC-SHA256 |
| `data/PlugController.kt` | вибір шляху (локально → хмара), опитування, історія |
| `ui/` | Jetpack Compose, Material 3 |
| `widget/`, `service/` | віджет, фоновий сервіс, розклад |

Тести протоколу (`app/src/test`) звіряють байти з еталонною бібліотекою
[tinytuya](https://github.com/jasonacox/tinytuya); еталони генерує `tools/gen_vectors.py`.

## Власний ключ підпису (необов'язково)

Типово APK підписується `app/debug.keystore`. Щоб використати свій ключ, додай у
Settings → Secrets and variables → Actions секрети `KEYSTORE_B64` (keystore у base64),
`KEYSTORE_PASSWORD`, `KEY_ALIAS`. Після зміни ключа старий APK треба буде видалити один раз.
